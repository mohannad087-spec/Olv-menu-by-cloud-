# جداول محمية بدون سياسات (RLS مفعّل بدون policies)

هاي الجداول فيها Row Level Security مفعّل **بدون أي سياسة**، يعني التطبيق (anon/authenticated) ما بقدر يقرأها ولا يكتب عليها مباشرة.
الوصول الوحيد إليها عن طريق دوال `security definer` بقاعدة البيانات أو دوال Edge بمفتاح الخدمة (service_role). هذا مقصود، مش خطأ.

| الجدول | ليش مقفول |
|---|---|
| `ai_usage` | عدّاد استهلاك الذكاء الاصطناعي، بتكتبه دوال Edge فقط |
| `approval_attempts` | محاولات الموافقات (حماية من التخمين) |
| `approvals` | موافقات المدير، بتمر عبر دوال |
| `attendance_bridge_tokens` | رموز جسر البصمة (مخزّنة مشفّرة SHA-256) |
| `daily_order_counters` | عدّاد رقم الطلب اليومي، بيتحدّث من دالة الطلب |
| `manager_pins` | أرقام المدير السرية |
| `menu_whatsapp_log` | سجل واتساب المنيو |
| `pin_attempts` | محاولات رقم «إعادة التصفير» (حدّ 5 محاولات/15 دقيقة) |
| `staff_meal_people` | أشخاص وجبات الموظفين |
| `staff_meals` | وجبات الموظفين |
| `table_nudges` | تنبيهات الطاولات |

**قاعدة:** لا تضيف سياسة لأي جدول هون إلا إذا لازم الواجهة تقرأه مباشرة؛ وقتها اكتب سياسة ضيّقة (حسب الدور) مش `using (true)`.
