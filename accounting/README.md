# محاسبة OLV — نظام محاسبي سحابي للمطعم

نظام محاسبة يعمل بالكامل من المتصفح دون الحاجة إلى خادم خاص، ومتصل بقاعدة
بيانات سحابية حقيقية على [Supabase](https://supabase.com) (مجانية للمشاريع
الصغيرة)، ويُنشر تلقائيًا عبر خدمة GitHub Pages الخاصة بهذا المستودع.

## الميزات

- تسجيل دخول آمن للموظفين عبر Supabase Auth
- **بيع سريع**: شاشة تعرض أصناف القائمة بالصور والأسعار والإضافات، تُبنى
  منها سلة وتتحول تلقائيًا إلى قيد مبيعات
- **المبيعات**: الفكرة نفسها الخاصة بالبيع السريع، بشكل قائمة/نموذج (مناسبة
  لإدخال عدة عمليات بيع بسرعة أو لمراجعة السجل)
- **المخزون**: مواد خام (لحم، جبن، خبز...) بكمياتها ووحداتها، ووصفة لكل
  صنف أو إضافة تحدد مقدار استهلاكه من كل مادة — أي عملية بيع من أي شاشة
  تُنقص المخزون تلقائيًا وفق الوصفة
- **المصروفات**: تسجيل المصروفات وتصنيفها (مشتريات، رواتب، إيجار...)
- **الخزينة**: تقفيل يومي للنقد ومقارنة المتوقع بالفعلي
- **التقارير**: أرباح وخسائر لأي فترة، وتوزيع المصروفات حسب التصنيف، وتصدير
  التقرير بصيغة PDF (زر "تصدير PDF" يفتح نافذة الطباعة، فاختر "حفظ كـ PDF")
- جميع البيانات محفوظة على السحابة (Supabase) ومتاحة من أي جهاز أو متصفح

## خطوات التشغيل (تُنفَّذ مرة واحدة)

1. **إنشاء مشروع Supabase مجاني**
   - انتقل إلى https://supabase.com وسجّل الدخول ثم أنشئ New Project.
   - انتظر حتى ينتهي إعداد المشروع (دقيقة أو دقيقتان).

2. **إعداد قاعدة البيانات**
   - من لوحة تحكم Supabase: **SQL Editor → New query**.
   - شغّل الملفات التالية **بالترتيب** (كل ملف مرة واحدة: الصق المحتوى ثم اضغط Run):
     1. [`schema.sql`](./schema.sql) — الجداول الأساسية (المبيعات، المصروفات، الخزينة)
     2. [`schema-products-addons.sql`](./schema-products-addons.sql) — المنتجات والإضافات (ضرورية لشاشة البيع السريع)
     3. [`schema-inventory.sql`](./schema-inventory.sql) — المخزون ووصفات الأصناف
   - إذا كان الهاتف يحوّل الشرطتين `--` إلى شرطة واحدة عند اللصق فتظهر رسالة
     syntax error، استخدم [`schema-no-comments.sql`](./schema-no-comments.sql)
     بدلًا من `schema.sql` (المحتوى نفسه دون تعليقات).

3. **ربط الموقع بالمشروع**
   - من Supabase: **Project Settings → API**.
   - انسخ **Project URL** و **anon public key**.
   - افتح ملف [`config.js`](./config.js) وضع القيمتين مكان:
     - `YOUR_SUPABASE_PROJECT_URL`
     - `YOUR_SUPABASE_ANON_PUBLIC_KEY`
   - احفظ التغييرات وارفعها (commit + push) إلى GitHub، وسيتحدث الموقع
     تلقائيًا عبر الإجراء الموجود مسبقًا (`.github/workflows/static.yml`).

4. **إنشاء حساب لصاحب المطعم وللموظفين**
   - من Supabase: **Authentication → Users → Add user**.
   - أدخل البريد الإلكتروني وكلمة المرور لكل موظف يحتاج إلى الدخول إلى النظام.
   - عند إنشاء أي حساب، يُضاف تلقائيًا إلى جدول `profiles` بدور `staff`.
   - لمنح صلاحية "owner" أو "manager": من **Table Editor → profiles**، عدّل
     عمود `role` للمستخدم يدويًا.

5. **فتح النظام وإعداد القائمة والمخزون**
   - `https://<اسم-المستخدم>.github.io/<اسم-المستودع>/accounting/login.html`
   - من **الإعدادات**: أضِف أصناف القائمة (الاسم، السعر، التصنيف، الصورة) والإضافات
   - من **المخزون → المواد الخام**: أضِف كل مادة (لحم، خبز، جبن...) بوحدتها وكميتها
   - من **المخزون → وصفات الأصناف**: حدد لكل صنف أو إضافة المواد الخام
     وكمية كل واحدة منها المستهلكة عند بيع وحدة واحدة — دون هذه الخطوة لن
     تُنقص عملية البيع أي شيء من المخزون (ستُسجَّل المبيعات فقط دون خصم مواد)

## ملاحظات أمان

- مفتاح `anon key` مصمَّم ليكون ظاهرًا في المتصفح، والحماية الفعلية تأتي من
  سياسات RLS في `schema.sql` التي تشترط تسجيل الدخول لأي عملية قراءة أو كتابة.
- لفصل صلاحيات owner/manager/staff بدقة أكبر (مثل السماح للمدير فقط بحذف
  القيود)، عدّل سياسات RLS في `schema.sql` بناءً على عمود `role`.
- يُفضَّل أن يبقى هذا المستودع **خاصًا (private)** إن كنت لا تريد أن يطّلع
  أحد على كود الموقع، مع العلم أن بيانات المحاسبة نفسها محمية بتسجيل الدخول
  بصرف النظر عن ذلك.

## هيكل الملفات

```
accounting/
  login.html                     صفحة تسجيل الدخول
  index.html                     لوحة التحكم الرئيسية (ملخص اليوم)
  pos.html                       بيع سريع (شبكة أصناف بالصور)
  sales.html                     بيع بشكل قائمة/نموذج، وسجل المبيعات
  inventory.html                 المواد الخام ووصفات الأصناف والإضافات
  expenses.html                  تسجيل وعرض المصروفات
  cash-register.html             تقفيل الخزينة اليومي
  reports.html                   تقارير الأرباح والخسائر، وتصدير PDF
  settings.html                  تصنيفات المصروفات، والمنتجات، والإضافات
  schema.sql                     الجداول الأساسية
  schema-products-addons.sql     المنتجات والإضافات
  schema-inventory.sql           المخزون والوصفات، ودالة record_sale
  config.js                      بيانات الاتصال بمشروع Supabase الخاص بك
  assets/                        التصميم (theme.css) والأكواد المشتركة (JS)
```

## ملاحظة حول حذف عمليات البيع

حذف قيد من سجل المبيعات (sales.html) يحذف القيد فقط، ولا يُعيد المواد
الخام المخصومة إلى المخزون تلقائيًا. في حال الحذف بالخطأ، عدّل كمية
المخزون يدويًا من صفحة المخزون.

## تطوير مستقبلي (اختياري)

- تنبيه تلقائي عند وصول مادة خام إلى حد التنبيه
- ربط الأدوار (owner/manager/staff) بصلاحيات أدق داخل الواجهة نفسها
- دعم أكثر من فرع للمطعم
