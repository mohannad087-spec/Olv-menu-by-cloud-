# المبيعات (`accounting/sales.html`): بتغلب على MASTER

الصفحة لمراجعة اللي انباع ولقيان أي طلب بسرعة. البيع اليومي من «بيع سريع»، والتحليل العميق بالتقارير.

- **الترتيب:** عنوان + تاريخ الفترة ← حبوب الفترة (اليوم / أمس / 7 أيام / هالشهر / فترة…) ← 4 أرقام ← رسم + (طرق الدفع والأكثر مبيعًا) ← قائمة الطلبات.
- الفترة الافتراضية **اليوم**. التواريخ بتوقيت الجهاز (مش UTC).
- **الأرقام:** إجمالي المبيعات (مع مقارنة: يوم واحد ← نفس اليوم الأسبوع الماضي، الشهر ← نفس الأيام من الشهر الماضي، غير هيك ← نفس الطول قبلها)، عدد الطلبات، متوسط الفاتورة، الملغى (عدد + قيمة، أحمر إذا في). 4 أعمدة ← 2 (≤900).
- **الرسم:** أعمدة زيتونية. يوم واحد ← ساعة بساعة (9 ص لـ 11 م على الأقل)، أكتر ← يوم بيوم. الأعلى رقمه مكتوب فوقه بالذهبي، وتحته جملة ملخّص. لمس/ماوس/Tab بيبيّن القيمة وعدد الطلبات.
- **طرق الدفع:** شريط واحد مقسوم (كاش زيتوني، شبكة ذهبي، توصيل `#c9a993`) + قائمة بالمبلغ والنسبة.
- **الأكثر مبيعًا:** أول 5 بالكمية، أول 3 رقمهم ذهبي، شريط زيتوني رفيع تحت كل اسم.
- **قائمة الطلبات:** سطر لكل طلب (وقت + رقم ← الأصناف + نوع/طاولة/زبون ← المبلغ + طريقة الدفع)، مجمّعة حسب اليوم مع مجموع اليوم لما الفترة أكتر من يوم. بحث (رقم الطلب، صنف، زبون، طاولة، هاتف) + حبوب تصفية بعدّاد (الملغاة بتطلع بس إذا في). 40 طلب وبعدين «عرض المزيد».
  - الضغط على الطلب بيفتح تفاصيله (طلب واحد مفتوح بالمرة): الأصناف مع «إلغاء الصنف»، الخصم والمستلم والباقي، سبب الإلغاء، إعادات الطباعة (بتنجاب وقت الفتح)، وأزرار «إعادة طباعة» و«إلغاء الطلب» (ضغط مطوّل).
  - عمود «الملاحظات» القديم ما بينعرض إذا الطلب فيه أصناف: كان مكرّر (الأصناف + المستلم + الخصم كلها أعمدة لحالها).
- **بيع يدوي:** للمالك والمدير بس، مخفي ورا زر «بيع يدوي» بأعلى الصفحة (للتسجيل بتاريخ سابق). زر الحفظ زيتوني (`.pay`).
