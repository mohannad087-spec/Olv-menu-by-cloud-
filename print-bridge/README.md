# جسر الطباعة (print-bridge)

برنامج صغير يعمل على جهاز كمبيوتر واحد داخل شبكة المطعم، مهمته الوحيدة
مراقبة عمليات البيع الجديدة في نظام محاسبة OLV وإرسال نسخة تلقائيًا إلى
طابعة المطبخ ونسخة إلى طابعة الفاتورة/الكاش — طابعتان حراريتان شبكيتان
(مثل Epson أو Star) متصلتان بنفس شبكة الواي فاي أو الشبكة السلكية
للمطعم.

## لماذا نحتاج هذا البرنامج؟

النظام (شاشة البيع السريع وباقي صفحات المحاسبة) هو موقع ويب عادي بدون
خادم خاص به، ويعمل من أي جهاز فيه متصفح (بما في ذلك آيباد). لكن متصفح
الآيباد (سفاري) لا يستطيع لأسباب تتعلق بأمان المتصفحات نفسها أن يتصل
مباشرة بطابعة على الشبكة المحلية ويرسل لها أوامر طباعة خام. لذلك نحتاج
جهاز كمبيوتر واحد فقط (لابتوب أو مكتبي عادي، ويمكن أن يكون رخيصًا جدًا،
حتى Raspberry Pi يكفي) يبقى مفتوحًا ومتصلًا بنفس الشبكة، ويقوم هو
بالاتصال بالطابعات نيابة عن النظام.

هذا الجهاز لا يحتاج أن يكون الجهاز الذي يستخدمه الكاشير — يكفي أن يعمل
عليه هذا البرنامج في الخلفية باستمرار (حتى لو لم يفتح أحد شاشته).

## خطوات التركيب (مرة واحدة فقط)

### 1. تركيب Node.js

نزّل ثبّت Node.js (النسخة 18 أو أحدث) من الموقع الرسمي:
https://nodejs.org — اختر النسخة الموصى بها (LTS).

### 2. نسخ هذا المجلد

انسخ مجلد `print-bridge` بالكامل إلى الجهاز الذي سيبقى يعمل باستمرار
(عبر USB، أو تنزيل المشروع من GitHub مباشرة على ذلك الجهاز).

### 3. تركيب المكتبات المطلوبة

افتح "موجه الأوامر" (Command Prompt / Terminal) داخل مجلد `print-bridge`
ونفّذ:

```
npm install
```

### 4. ضبط بيانات الاتصال بـ Supabase

انسخ ملف `.env.example` وأعد تسميته إلى `.env`، ثم افتحه بأي محرر نصوص
واملأ:

- `SUPABASE_URL`: رابط مشروعك في Supabase (من Project Settings → API).
- `SUPABASE_SERVICE_KEY`: مفتاح **service_role** (وليس anon key!) من نفس
  الصفحة. هذا المفتاح سري جدًا — لا ترفعه إلى GitHub ولا تشاركه مع أحد،
  لأنه يعطي صلاحية كاملة على قاعدة البيانات. الملف `.env` مستثنى تلقائيًا
  من Git (موجود في `.gitignore`).

### 5. معرفة عنوان IP لكل طابعة

كل طابعة شبكية حرارية لها عنوان IP خاص بها على شبكة المطعم، عادة يمكن
معرفته من:
- شاشة الطابعة نفسها (إن وجدت) عبر قائمة الإعدادات → الشبكة.
- طباعة "صفحة اختبار الشبكة" من أزرار الطابعة (راجع دليل الطابعة).
- تطبيق إدارة الراوتر/الشبكة لديك (يعرض كل الأجهزة المتصلة وعناوينها).

المنفذ الافتراضي لطباعة ESC/POS الخام في كل الطابعات الحرارية الشبكية
تقريبًا هو **9100** — اتركه كما هو ما لم تكن طابعتك مضبوطة على منفذ آخر.

### 6. اختبار الاتصال بكل طابعة (قبل ربط كل شيء)

نفّذ من داخل مجلد `print-bridge`:

```
node test-print.js 192.168.1.50
```

(استبدل الرقم بعنوان IP طابعتك الفعلي). إذا خرجت ورقة اختبار من
الطابعة فالاتصال سليم. كرر الاختبار لكل طابعة على حدة.

### 7. ضبط الطابعات من داخل النظام

افتح صفحة **الإعدادات** في نظام المحاسبة → قسم **"الطباعة التلقائية"**،
وفعّل كل طابعة وأدخل عنوان IP الخاص بها (ونفس المنفذ الذي اختبرته أعلاه).

### 8. تشغيل البرنامج

```
npm start
```

اترك هذه النافذة مفتوحة — طالما هي تعمل، ستُطبع كل عملية بيع جديدة
تلقائيًا. أغلق النافذة فقط إذا أردت إيقاف الطباعة التلقائية مؤقتًا.

## تشغيل البرنامج تلقائيًا دون تدخّل يومي (موصى به)

لتفادي الحاجة لفتح البرنامج يدويًا كل يوم، استخدم أداة `pm2` التي تُبقي
البرنامج يعمل دائمًا وتُعيد تشغيله تلقائيًا عند أي خطأ أو إعادة تشغيل
الجهاز:

```
npm install -g pm2
pm2 start src/index.js --name olv-print-bridge
pm2 save
pm2 startup
```

الأمر الأخير `pm2 startup` سيطبع لك أمرًا إضافيًا يجب نسخه وتنفيذه مرة
واحدة، وبعدها يعمل البرنامج تلقائيًا من جديد كلما أُعيد تشغيل الجهاز.

## متابعة حالة الطباعة

من صفحة **الإعدادات** في النظام، قسم "الطباعة التلقائية"، يظهر جدول
بآخر عمليات الطباعة وحالتها (تمت الطباعة / خطأ / الطابعة غير مفعّلة)،
مع زر "إعادة المحاولة" لأي عملية طباعة فشلت (مثلًا بسبب انقطاع الشبكة
لحظيًا) — يعيدها البرنامج تلقائيًا في المحاولة التالية.

## أسئلة شائعة

**هل يجب أن يكون هذا الجهاز مفتوحًا طوال الوقت؟**
نعم، طالما تريد الطباعة التلقائية أن تعمل. إن أُغلق الجهاز أو انقطع عن
الشبكة، تتراكم طلبات الطباعة بحالة "قيد الإرسال" وتُطبع تلقائيًا فور
إعادة تشغيله والاتصال بالشبكة من جديد — لا تُفقد أي عملية بيع.

**ماذا لو كانت طابعتي مقاس 58مم وليس 80مم؟**
افتح ملف `src/ticket-builder.js` وغيّر قيمة `PRINTER_WIDTH_PX` من `576`
إلى `384`.

**هل يمكن استخدام نفس الطابعة للمطبخ وللفاتورة معًا؟**
نعم، فقط أدخل نفس عنوان IP في كلا الحقلين داخل صفحة الإعدادات.
